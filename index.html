          Coordinates and time zone
          
      
            
      For a place not in the list, or to be exact: paste coordinates from a map (e.g. 43.9455, -78.8968) into Latitude.

      Zawal is true noon, when the sun crosses the meridian. Some timetables wait a few minutes after it.
      

        
      
          Night and high latitudes
          
      
            
      
              The night runs from sunset to
              
      
                
                
              
      
              
      Used for midnight (the end of Isha, if you choose it) and the last third of the night.
      
            
      
            
            
      Far from the equator in summer the sky may never get dark enough for the Fajr or Isha angle. These rules place them within the night instead; days that use one are marked in the timetable.

          Add the file to your calendar
          
      
            
        
              
      1. Google: on a computer, open Settings → Import & export, choose the .ics and pick a calendar. A new one, such as “Prayer times”, is easiest to remove or recolour later.
        2. 
              
      2. Apple: open the .ics; Calendar asks which calendar to add it to.
        3. 
              
      3. Outlook: Calendar → Add calendar → Upload from file.
        4. 
            
      
            
      The file is a snapshot. To change it, delete that calendar and import a new file. A file for the same place and days replaces matching events in calendars that support it.
      
          
      
        
      
      
      
    
      
  
      

      


  
      How your location stays private
      
  
      
    
      No server. This is a static page. The times and the .ics are worked out by JavaScript in this tab.
      
    
      No network. The page's security policy (connect-src 'none') stops it from sending anything over the network, even by mistake. The city list is part of the page, so picking a city looks nothing up.
      
    
      Your location. “Use my location” asks your browser, which asks you first. The coordinates stay in this tab.
      
    
      What's kept. Your settings, place included, are saved in this browser so they're there next time. “Reset to defaults” clears them. The display settings (theme, background) are shared with the other sites on areeb-ece.github.io.
